# Dashboard Page

**Agent**: ui
**Priority**: high
**Output**: client/src/components/Dashboard.jsx

## Objective
Build a production-ready React Dashboard page using Tailwind CSS.

## Requirements
- Sidebar with nav links: Dashboard, Projects, Subscriptions, Settings
- Read user from localStorage
- If no user redirect to /
- Welcome message with user name
- Three stat cards: Total Projects, Active Subscription, Member Since
- Projects table with empty state message
- Logout button clears localStorage and redirects to /
